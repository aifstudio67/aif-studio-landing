# AIF Studio landing

Лендинг AIF Studio на Next.js. Включает кейсы из папки `public/portfolio`, контактные данные и форму, которая открывает письмо с заполненными данными в почтовом приложении посетителя.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

## Проверка production-сборки

```bash
npm run build
npm start
```

## Timeweb Cloud App Platform

1. Загрузите репозиторий в GitHub, GitLab или Bitbucket.
2. В App Platform создайте приложение, подключите репозиторий и выберите пресет **Next.js**.
3. Включите SSR и оставьте команду запуска `npm start`.
4. После успешного деплоя привяжите свой домен в панели приложения.

Timeweb сам установит зависимости и соберёт проект. Подробная официальная инструкция: https://timeweb.cloud/docs/apps/deploying-frontend-apps/nextjs
